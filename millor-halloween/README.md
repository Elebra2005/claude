# 🎃 Миллор Групп: Секретная лаборатория
**Halloween Bingo — Выживи до пятницы!** · 30 октября 2026, 10:00–17:00 (МСК) · до 50 участников

Браузерная игра-бинго для сотрудников Миллор Групп: поле 4×4, 16 заданий (10 проверяются автоматически, 6 творческих проверяет организатор), рейтинг «Зал славы», пульт организатора.

## Что внутри

| Часть | Файл |
|---|---|
| Сервер (Node.js ≥ 22.13, **без внешних зависимостей**, встроенный SQLite) | `server.js` |
| 16 заданий, ключи ответов (только на сервере), линии БИНГО, предсказания | `tasks.js` |
| Иллюстрация лаборатории для «Охотника за привидениями» | `scene.js` |
| Игра для участников (адаптивная, телефон и компьютер) | `public/index.html`, `app.js`, `styles.css` |
| Пульт организатора | `public/admin.html`, `admin.js`, `admin.css` (адрес `/admin`) |
| Сквозные тесты (16 сценариев) | `test/game.test.js` — `npm test` |
| Развёртывание с HTTPS | `Dockerfile`, `docker-compose.yml`, `Caddyfile` |

Данные (база `game.db`, фото, логотип) хранятся в папке `DATA_DIR` (по умолчанию `./data`). Фото лежат в закрытой папке и отдаются только автору, организатору или — после одобрения и с согласия автора — в «Галерее».

## Быстрый запуск на своём компьютере (для проверки)

```bash
cd millor-halloween
ADMIN_PASSWORD='придумайте-пароль' node server.js
# игра:    http://localhost:3000
# пульт:   http://localhost:3000/admin
```
Если `ADMIN_PASSWORD` не задан, пароль сгенерируется и сохранится в `data/admin-password.txt`.

## Публикация в интернете (HTTPS)

Нужны: VPS с Docker (подойдёт любой российский хостинг — Timeweb Cloud, Selectel, Yandex Cloud, REG.RU; 1 vCPU / 1 ГБ RAM хватает с запасом) и домен или поддомен, например `halloween.millor.ru`, с A-записью на IP сервера.

```bash
git clone <репозиторий> && cd <репозиторий>/millor-halloween
DOMAIN=halloween.example.ru ADMIN_PASSWORD='надёжный-пароль' docker compose up -d
```
Caddy сам выпустит сертификат Let's Encrypt — через минуту игра будет доступна по `https://halloween.example.ru`. Хостинг в РФ гарантирует доступность для сотрудников по всей России.

Резервная копия: `docker compose exec game sh -c 'cd /data && tar c .' > backup.tar`.

## Как войти администратору

1. Откройте `https://<домен>/admin` и введите `ADMIN_PASSWORD`.
2. **Коды** → создайте 50 кодов (вид `MLR-XXXX-XXXX`) → скачайте CSV или распечатайте карточки → раздайте участникам по одному.
3. **Настройки** → проверьте время (по умолчанию 30.10.2026 10:00–17:00 МСК), загрузите официальный логотип (PNG/JPEG/WebP до 1 МБ; пока его нет, показывается текстовое название).

Вкладки пульта: Статистика · Проверка (очередь творческих ответов: текст/фото, подтвердить/отклонить с комментарием, отмена подтверждения) · Участники (прогресс, мини-поле, выгрузка в CSV для Excel) · Коды (создание, отключение, удаление) · Задания (правка формулировок; ключи ответов не меняются) · Активности (секретное задание дня, коллективная миссия) · Награды (жеребьёвка) · Настройки (время, запуск/остановка, логотип, демо-режим, удаление данных).

## Как протестировать до мероприятия (демо-режим)

1. **Настройки → «Создать 3 тестовых кода»** (коды вида `TEST-…`).
2. Откройте игру на телефоне и на компьютере, войдите разными тестовыми кодами. Тестовые участники играют **вне расписания**, не попадают в настоящий рейтинг, статистику и награды.
3. Пройдите задания. Правильные ответы видны во вкладке «Задания» пульта.
4. В пульте поставьте галочку **«Тестовые данные»** → «Проверка» → одобрите творческие ответы; на поле участника придут уведомления и анимация БИНГО (опрос каждые 20 с).
5. Войдите тем же кодом с другого устройства — прогресс сохранится.
6. Перед запуском: **Настройки → «Очистить тестовые данные»**.

## Правила подсчёта

* 10 баллов за задание, +30 за каждую из 10 линий (4 строки, 4 столбца, 2 диагонали). Максимум 16×10 + 10×30 = **460**.
* Баллы и линии считаются на сервере по статусам заданий, поэтому двойное начисление невозможно, а после подтверждения/отмены творческого ответа всё пересчитывается автоматически.
* Викторины и головоломки — до 3 попыток (одинаково для всех); некорректный ввод попытку не тратит. В «Охотнике за привидениями» промахи бесплатны, в «Выжить на созвоне» неверных ответов нет.
* Секретное задание дня и предсказания на рейтинг не влияют.
* Награды: «Определить 1–3 места» (равные баллы — криптографически случайный жребий, ход жеребьёвки пишется в журнал с московским временем), затем «Самый креативный» (выбор организатора) и «Случайный участник с БИНГО» — только среди ещё не награждённых. Жеребьёвка блокируется, пока в очереди есть непроверенные ответы.

## Безопасность и приватность

* Вход участника — по индивидуальному коду (без паролей), один профиль на код; сессия в HttpOnly-cookie (`Secure` за HTTPS). Отключение кода в пульте сразу разлогинивает участника.
* Ограничение подбора кодов и пароля администратора; защита от CSRF (только JSON и проверка Origin); строгая CSP.
* Ключи ответов не передаются в браузер, все проверки — на сервере. Исключение по природе задания: в «Охотнике за привидениями» привидения нарисованы на картинке, но засчитывает клики сервер.
* Фото: только JPEG/PNG/WebP (проверяется сигнатура файла), до 5 МБ; браузер перед отправкой уменьшает фото и удаляет EXIF (включая геометки).
* Творческие ответы и фото не показываются в рейтинге. В «Галерее» — только одобренные ответы с галочкой согласия автора.
* После мероприятия: выгрузите CSV, затем **Настройки → «Удалить все игровые данные»** (по желанию — вместе с кодами).

## Важные оговорки

* Препараты Реглисам, Фламин и Кардиовален используются только как корпоративные пасхалки — без медицинских показаний и свойств.
* Сервер рассчитан на один процесс (SQLite) — для 50 участников этого с запасом достаточно; не запускайте несколько копий на одной базе.
