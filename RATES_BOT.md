# Бот курсов валют и просадок

Каждый день присылает в Telegram курсы трёх валют по ЦБ РФ и отдельно
пишет, когда ловит просадку. Сделан под задачу «поймать дешёвый юань перед
покупкой машины в Китае», но валюты настраиваются.

## Что шлёт

**Ежедневная сводка** (по умолчанию 10:00 МСК):

```
📅 Курсы ЦБ на 05.09.2026

🇨🇳 Юань CNY  11,5480 ₽
   ⚪️ день +0,02% · неделя −0,31% · месяц −2,04%
   90 дней: 11,54 … 12,27 ₽
   ●········· дёшево — низ коридора

🇺🇸 Доллар USD  80,9500 ₽
   ...
🎯 Ваши цели: CNY ≤ 11,00
```

Шкала `●·········` показывает, где курс внутри 90-дневного коридора:
точка слева — у минимума (покупать выгодно), справа — у максимума.

**Уведомление о просадке** приходит вне расписания, когда срабатывает
любое из правил:

| Правило | Порог по умолчанию | Переменная |
|---|---|---|
| падение за день | −0,8 % | `DIP_DAILY_DROP_PCT` |
| новый минимум за N дней | 30 дней | `DIP_LOW_WINDOW_DAYS` |
| ниже скользящей средней | на 2 % за 30 дней | `DIP_BELOW_MA_PCT`, `DIP_MA_WINDOW_DAYS` |
| внутридневное падение на бирже (юань) | −1 % | `MOEX_INTRADAY_DROP_PCT` |
| личная цель по курсу | — | команда `/target` |

Одно и то же событие дважды не приходит: отметки об отправке хранятся в
базе с ключом по дате курса.

## Откуда данные

- **ЦБ РФ**, `cbr.ru/scripts` — официальный курс, обновляется раз в рабочий
  день около 15:00 МСК. Коды валют бот берёт из ответа ЦБ, а не хардкодит,
  и учитывает номинал (у иены он 100, у юаня до 2023 года был 10).
- **Мосбиржа**, ISS API — биржевой курс `CNYRUB_TOM` в реальном времени.
  Нужен потому, что платите вы по рынку, а не по вчерашней фиксации ЦБ.
  Доллар и евро на MOEX не торгуются с июня 2024 года, поэтому биржевой
  блок работает только по юаню. Если ISS недоступен — блок просто
  пропускается, сводка уходит без него.

При первом запуске бот подтягивает историю за `BACKFILL_YEARS` лет (по
умолчанию 8) и складывает в SQLite — дальше статистика и `/seasonality`
считаются локально, без обращений к ЦБ.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | подписаться |
| `/rates` | курсы прямо сейчас |
| `/dip` | есть ли просадка на сегодня |
| `/history CNY 90` | минимум, максимум, средний и итог за N дней |
| `/seasonality CNY` | по каким месяцам валюта исторически дешевела |
| `/target CNY 10.9` | написать, когда курс упадёт до значения |
| `/targets`, `/untarget CNY` | список целей и снятие |
| `/digest_time 09:30` | своё время сводки (МСК) |
| `/mute`, `/unmute` | выключить/включить уведомления о просадках |
| `/settings` | текущие настройки и пороги |
| `/stop` | отписаться |

`/seasonality` считает изменение курса за календарный месяц (последний
рабочий день месяца к последнему рабочему дню предыдущего) по всей
загруженной истории ЦБ и показывает среднее, медиану, долю лет со
снижением и размер выборки. `/seasonality CNY 2023` — только с 2023 года,
чтобы отсечь досанкционный период с другой структурой рынка.

## Развёртывание

```bash
cd /root && git clone https://github.com/elebra2005/claude.git rates-bot \
  || (cd /root/rates-bot && git pull origin claude/yuan-exchange-rate-bot-jste43)
cd /root/rates-bot && git checkout claude/yuan-exchange-rate-bot-jste43

cp .env.example .env
nano .env          # вписать RATES_BOT_TOKEN и ADMIN_CHAT_IDS

docker compose up -d --build
docker compose logs -f rates-bot
```

Токен — у [@BotFather](https://t.me/BotFather), свой chat_id — у
[@userinfobot](https://t.me/userinfobot). Если `ADMIN_CHAT_IDS` заполнить,
подписка появится сразу, без `/start`.

В логах при первом запуске должно быть примерно так:

```
rates_bot: Валюты: CNY, USD, EUR, основная: CNY
rates_bot.service: CNY: загружаю историю с 2018-09-07
rates_bot.service: CNY: сохранено 2087 значений
rates_bot.scheduler: Курсы ЦБ обновлены на 2026-09-05
```

База лежит в докер-томе `rates-data` и переживает пересборку образа.

## Настройки

Все — через `.env`, полный список с комментариями в `.env.example`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `RATES_BOT_TOKEN` | — | токен бота, обязателен |
| `ADMIN_CHAT_IDS` | пусто | кого подписать при старте |
| `CURRENCIES` | `CNY,USD,EUR` | какие валюты слать |
| `PRIMARY_CURRENCY` | `CNY` | основная — для `/dip` без аргументов и для биржевого блока |
| `DIGEST_TIME` | `10:00` | время сводки, МСК |
| `POLL_INTERVAL` | `900` | как часто опрашивать ЦБ, секунды |
| `BACKFILL_YEARS` | `8` | глубина истории при первом запуске |
| `DB_PATH` | `/data/rates.db` | файл базы |

Пороги просадки перечислены в таблице выше. После правки `.env`:

```bash
docker compose up -d
```

## Ограничения

- Курс ЦБ — фиксация на дату, а не рыночная цена покупки. Разница с курсом
  банка или брокера обычно 0,5–2 %; биржевой блок по юаню как раз для того,
  чтобы видеть реальный рынок.
- `/seasonality` — статистика прошлого, не прогноз. После 2022 года
  структура валютного рынка сильно изменилась, поэтому длинные ряды стоит
  смотреть с оговоркой и сравнивать с `/seasonality CNY 2023`.
- ЦБ не публикует курсы в выходные и праздники — в эти дни сводка повторит
  последнюю рабочую дату.
