## Постоянные правила
- Конфиденциальность: нигде не должно быть названия компании, цеха и города. Проверка перед выдачей:
  перед выдачей — grep по стоп-списку (список слов — в CLAUDE.md репозитория ceh-epoksid) должен дать 0, в т.ч. по тексту PDF/docx. Документы проектировщика не упоминаются — «исходная схема ТХ».
- В git ничего больше 100 МБ. Нельзя `git stash`, autostash, `git add -A`; коммитить только свои пути; push после каждого коммита (с повторами 2/4/8/16 с).
- Атрибуция коммитов: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` + `Claude-Session: https://claude.ai/code/session_01DXDrNZvUTJDwRGAmxHaPFX`. Названия моделей ИИ в файлах репозитория не фигурируют.
- Не использовать `pkill -f`/`pgrep -f` с шаблоном, который есть в собственной командной строке (убивает себя — выход 144); убивать по PID / по cwd из /proc.
- Экономно; без субагентов. Долгие шаги — в фоне, с мониторами; контейнер может перезапуститься (проверки коллизий — возобновляемые по блокам).
