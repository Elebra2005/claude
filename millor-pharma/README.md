# 🎃 Миллор Фарма: Секретная лаборатория — Halloween Bingo

30 октября 2026, 10:00–17:00 (МСК), 40–50 участников. Сервер на Node.js ≥ 22.13 без внешних библиотек, база SQLite, HTTPS через Caddy.

## Установка на сервер (Ubuntu 22.04/24.04)

```bash
curl -fsSL https://get.docker.com | sh
git clone -b claude/amazing-planck-1t72g1 https://github.com/elebra2005/claude.git
cd claude/millor-pharma
DOMAIN=ваш-домен.ru ADMIN_EMAIL=ваша@почта.ru docker compose up -d --build
docker compose logs game | grep "Код первой настройки"
```

DNS: A-запись домена должна указывать на IP сервера. Сертификат HTTPS выпускается автоматически (порты 80 и 443 должны быть открыты).

## Права администратора

* Админ — один человек, адрес задаётся переменной `ADMIN_EMAIL`. Пароля в коде нет.
* При первом запуске сервер создаёт одноразовый **код настройки** (в логах и в `/data/admin-setup.txt`). Откройте `https://домен/admin`, введите адрес, код и придумайте пароль (от 12 символов). Пароль хранится только в виде хэша scrypt.
* Забыли пароль: `docker compose exec game node server.js --reset-admin` — выдаст новый код настройки.
* Права проверяет сервер при каждом запросе; участник по ссылке `/admin` или подменой параметров доступа не получит. Вход ограничен по числу неудачных попыток.
* Роль «Тестовая роль» (галочка вверху кабинета) работает только с тестовыми участниками: сервер отклоняет изменения реальных данных из этого режима.

## Порядок работы организатора

1. Раздайте участникам ссылку на сайт. Кодов нет: в первый раз человек вводит имя и фамилию, выбирает «Офис»/«Удалённо» и **сам придумывает PIN из 4 цифр**; потом входит по имени и PIN (вкладка «Войти»), в том числе с другого устройства.
2. **Настройки → Логотип**: загрузите официальный логотип (без него показывается текстовое название).
3. **Репетиция**: включите «Тестовая роль», нажмите «Создать тестовых участников» («Настройки → Тестовый режим»; вход по имени и PIN 1234), войдите ими с нескольких устройств, пройдите задания, проверьте творческие работы, «Подвести итоги», затем «Очистить тестовые данные».
4. **30 октября**: игра стартует автоматически в 10:00 МСК (или кнопкой «Запустить игру» на дашборде). «Пауза» останавливает приём *новых* попыток; в 17:00 приём закрывается сам.
5. **Проверка творческих работ** (вкладка «Проверка»): отметьте критерии, система посчитает баллы. «Подтвердить результат», «Вернуть на исправление» (одно исправление) или «Отклонить».
6. **Ошибочная оценка**: карточка участника → «Скорректировать оценку» (с причиной). Все начисления и правки — в «Настройки → История».
7. **Итоги**: вкладка «Рейтинг и победители» → «Подвести итоги» (при полном равенстве среди призёров проводится жеребьёвка, ход записывается в журнал). Участники увидят экран «ЛАБОРАТОРИЯ СПАСЕНА!». «Выгрузить в CSV» — таблица по всем 16 заданиям, бонусам и итогу.
8. **После мероприятия**: скачайте CSV и резервную копию (JSON), затем «Удалить все игровые данные».

**Обновление на сервере:** `cd ~/claude && git pull && cd millor-pharma && docker compose up -d --build` — данные сохраняются, переход со входа по кодам делается автоматически.

## Правила подсчёта (реализованы на сервере)

* Автоигры: 2 попытки. Итог = `max(первая, max(0, вторая − 2))`. Первая попытка на 10 закрывает задание. Попытка тратится при нажатии «Начать попытку», таймер серверный, обновление страницы его не сбрасывает; по истечении времени сохранённые ответы засчитываются автоматически.
* № 3: подсказка −5 баллов, штраф действует и на второй попытке (плюс обычные −2); результат не ниже 0.
* Творческие: одна отправка, одно исправление после возврата.
* БИНГО: 10 линий (4 строки, 4 столбца, 2 диагонали), каждая из 4 клеток ≥ 8 баллов → +30. Максимум 460. Линии считаются заново из оценок, поэтому бонус не дублируется и пропадает при понижении оценки.
* Равенство: баллы → БИНГО → заданий на 10 → меньше попыток → жеребьёвка организатора.
* Раскладка поля: `16 2 12 7 / 5 10 8 11 / 3 1 6 9 / 15 14 4 13`.
* № 10: 10 секунд на вопрос (меняется в «Настройки → Таймеры»). Во время игры изменение правил требует подтверждения и причины и пишется в журнал.

## Безопасность и приватность

PIN хранится только в виде хэша scrypt с солью и секретом сервера. Подбор ограничен: 5 неверных PIN блокируют вход этого имени на 10 минут, плюс лимит попыток с одного адреса. Забытый PIN организатор сбрасывает в карточке участника: человек задаёт новый PIN при следующем входе, результаты сохраняются. Имя занимает первый, кто его ввёл; если имя заняли чужие, организатор удаляет такой профиль или сбрасывает PIN. Правильные ответы лежат только на сервере. Фото и видео — в закрытой папке, доступны автору и администратору (поддерживается просмотр видео без скачивания). Допустимы JPEG/PNG/WebP до 6 МБ и MP4/MOV/WebM до 40 МБ; тип проверяется по содержимому. Длительность видео (15 с) проверяется в браузере участника, сервер её не измеряет — организатор видит видео и может вернуть слишком длинное.
