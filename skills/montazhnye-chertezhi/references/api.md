# API движка draw.py

Все координаты — миллиметры, ось Y вниз, начало — левый верхний угол листа.
Лист — `Sheet(name, w=420.0, h=297.0)`: A3 альбом по умолчанию, A1 — `Sheet(..., 841.0, 594.0)`.

## Содержание
1. Примитивы
2. Символы арматуры (с проверкой стыков)
3. Оформление
4. Служебные поля Sheet
5. Вывод
6. Размещение подписей и проверка
7. Типовые размеры в мм (подобраны на реальном проекте)

## 1. Примитивы
| Вызов | Что делает |
|---|---|
| `poly(pts, lw=0.35, color=INK, dash=None, closed=False, fill=None, nc=False)` | ломаная/контур. `dash`: `'dash'` рукав, `'axis'` осевая, `'dot'`. `nc=True` — не трубопровод (пол, мешалка): проверка её не трогает |
| `line(x1,y1,x2,y2, **kw)`, `rect(x,y,w,h, **kw)` | обёртки над poly |
| `circle(cx,cy,r, lw, color, fill, dash)` | окружность |
| `text(x,y,s, size=2.5, anchor='start'/'middle'/'end', bold=False, color=None)` | если в тексте есть «?», он автоматически красный (RED) — это пометка «замерить/уточнить» |
| `arrow(x,y,ang)`, `stub_arrow(x,y,'right'/'left'/'up'/'down')` | стрелка; stub — «линия уходит на другой лист / в вытяжку» |
| `dim(x1,y1,x2,y2, off, label)` | линейный размер со стрелками |
| `leader(x,y,tx,ty,s)` | выноска с полкой |
| `axis(x1,y1,x2,y2)` | осевая |

## 2. Символы арматуры
Каждый символ регистрируется в `sheet.symbols`, и `check.py` проверяет, что с обеих сторон вдоль оси к нему подходит линия.
| Вызов | Что |
|---|---|
| `clamp(x,y,orient,tag,tag_side,w,size)` | кламповое соединение: 2 ферулы + хомут. `orient` — направление трубы (`'h'`/`'v'`). `tag` — номер в синем кружке, `tag_side` ±1 — с какой стороны. `w` — полуширина для крупных аппаратных клампов (K91/K119). `size` — подпись ферулы (K25…), ставится автоматически `place_sizes` |
| `ball_valve(x,y,orient,s=3.2)` | кран шаровой; линия прерывается на символе сама |
| `check_valve(x,y,direction='down',s=3.0)` | обратный клапан, остриё по потоку |
| `gauge(x,y,r=3.5,up=True,label='PI')` | манометр на отводе |
| `reducer(x,y,orient,big,small,L=5)` | концентрический переход (big/small — полувысоты торцов) |

Полудлина клампа вдоль оси ≈ 1,8 мм: подводите трубы к `x ± 1.8`. Пример: кламп в x=50 → труба слева кончается в 48.2, справа начинается с 51.8.

## 3. Оформление
| Вызов | Что |
|---|---|
| `frame(title, code, sheet_no, sheets, scale='б/м', org=None, project=None)` | рамка + упрощённая основная надпись (форма 1 ГОСТ 2.104) в правом нижнем углу, 185×55. Организация/проект — из `draw.ORG`, `draw.PROJECT` или аргументов |
| `table(x,y,colw,rows,rowh=5,size=2.2,header=True)` | таблица (ведомость, перечень, сводка) |
| `legend.drawings_legend(sheet_no, n_sheets, code)` | готовый лист «Условные обозначения» |

## 4. Служебные поля Sheet
- `items` — список примитивов; `symbols` — символы для проверки; `nocheck` — индексы items, которые не трубопровод.
- `vessels` — список `(x0,y0,x1,y1)` аппаратов: концы линий внутри них (погружные трубки, сифоны) не считаются «висящими».
- `pending_sizes` — подписи ферул, их расставляет `place_sizes`.
- `keep_order=True` — рисовать в порядке добавления (по умолчанию толстые трубы уходят под символы).

## 5. Вывод
- `to_svg(sheet)` → строка SVG (`viewBox` в мм, `width/height` в mm — открывается в браузере в натуральную величину).
- `to_vsdx(sheets, template_dir, out_path)` → редактируемый Visio: каждая линия, круг, текст — отдельная фигура. `template_dir` — распакованный `assets/visio-template.vsdx`.
- PDF: `node scripts/export_pdf.js out.pdf list-1.svg … --png превью/` (формат страницы берётся из viewBox, листы A3 и A1 можно смешивать).

## 6. Размещение подписей и проверка
- `place.place_sizes(sheet)` — вызвать после построения листа: ищет свободное место для подписей ферул рядом с номером соединения.
- `python3 check.py project.py` — по всем листам из `build()`:
  - символ не присоединён к линии;
  - висит конец линии (не касается символа/линии/аппарата и рядом нет подписи);
  - подписи накладываются друг на друга, на номера соединений, на символы, лежат на линии, пересекают окружность.
  Код выхода 1 при замечаниях — цикл «правка → проверка» до нуля.

## 7. Типовые размеры (мм)
- Толщины: труба кламповая 1.6–2.0, малая линия 1.0–1.2, рукав 0.9 штрих, трубка 0.45, выноски/размеры 0.18.
- Текст: заголовок листа 3.0 bold, позиция аппарата 2.2–3.0 bold, пояснения 1.7–2.0, таблицы 1.85.
- Шаг между соседними клампами на одной линии — не меньше 12 мм, иначе номера в кружках наползают.
- Номер соединения — кружок r=2.9 в 4–5 мм от трубы; ставьте `side` так, чтобы кружки соседних соединений смотрели в разные стороны или стояли не ближе 7 мм.
