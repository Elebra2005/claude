# Исходные документы заказчика (только чтение)

Раскладывать по подпапкам:
- `tehnologiya/` — регламенты, описание процесса по каждому продукту (эпоксидная смола, аминные и аллильные отвердители): стадии, загрузки, температуры, давления, вакуум, времена; материальный баланс; паспорта/СДС на сырьё.
- `oborudovanie/` — чертежи и паспорта оборудования, **таблицы штуцеров** (DN, PN, тип присоединения, ориентация, отметки), опросные листы.
- `planirovka/` — планы этажей, разрезы, отметки площадок, расстановка оборудования, эстакады, проходы.
- `sxemy/` — существующие схемы (технологические, электрические, вентиляции и т. п.).
- `prochee/` — всё остальное: ТУ, требования заказчика, уже купленное оборудование, поставщики, стандарты (ГОСТ / DIN, фланцы / клампы).

Форматы: PDF, сканы, фото, XLSX/CSV, DOCX. DWG/КОМПАС — экспортировать в PDF или DXF.
Имена файлов — со смыслом: `R-101_chertezh.pdf`, `reglament_epoksidnaya_smola.pdf`.
