# Поздравление Александра — три ролика

Сценарий: `alexander-birthday.json` — 24 сцены, три части (`rolik-1`, `rolik-2`,
`rolik-3`). Сцены сцеплены сквозь весь сценарий: последний кадр каждой сцены
становится стартовым кадром следующей (`continue_from`), поэтому стыки внутри
роликов и на переходах 1 → 2 → 3 идут без визуального скачка.

## Запуск

```bash
export HF_KEY="<key_id>:<key_secret>"
pip install aiohttp          # ffmpeg тоже нужен: сцепка кадров и склейка

cd /путь/к/репозиторию

# сначала посмотреть, что уйдёт в API, и хронометраж — бесплатно
python3 scenario.py run scenarios/alexander-birthday.json --dry-run

# генерация: сцепленные сцены идут по очереди, склейка по роликам
python3 scenario.py run scenarios/alexander-birthday.json \
    --out-dir out/alexander --concat-parts
```

Получится `out/alexander/rolik-1.mp4`, `rolik-2.mp4`, `rolik-3.mp4` плюс
отдельные клипы сцен и `manifest.json`. Прерванный прогон продолжается тем же
запуском — готовые сцены не перегенерируются.

Пересобрать одну сцену: удалить её строку из `manifest.json` (или файл клипа) и
запустить ещё раз. Все три ролика одним файлом — добавить `--concat out/alexander/full.mp4`.

## Хронометраж

В брифе стояло 25–30 секунд на ролик, но реплик там примерно на 2,5 раза
больше: русская разговорная речь идёт ~2,5 слова в секунду, плюс паузы и смех.
Сейчас хронометраж такой:

| ролик | сцен | длительность |
|---|---|---|
| `rolik-1` — раздевалка | 6 | ~37 с |
| `rolik-2` — коридор и «Спартак» | 8 | ~51 с |
| `rolik-3` — подарок, тоннель, финал | 10 | ~64 с |

Если нужно именно 25–30 секунд, придётся резать реплики — скажите, и я соберу
укороченный вариант. Кандидаты на сокращение, без которых шутки не рассыпаются:

* ролик 1 — «Тактика простая: …не получить жёлтую за лишние слова» и ответ «Уже звучит рискованно»;
* ролик 2 — блок «команда играла на результат / партнёры / конкуренты / финансовый результат» (4 реплики подряд);
* ролик 3 — «А если что-то пойдёт не так? — Скажем, была турбулентность» и перечисление «Смелых решений / Больших проектов / Побед».

## Что учтено из брифа

* **Персонажи.** Паспорт четверых футболистов (внешность, форма) прописан в
  `defaults.preamble` и подставляется в начало каждого промпта. Лица вымышленные,
  без копий известных игроков.
* **Звук.** `generate_audio: true`, у каждой сцены своё описание в `sound` —
  раздевалка, шаги по бетону, эхо тоннеля, рёв трибун. Музыки в генерации нет,
  как и просили: её кладут при монтаже.
* **Речь.** Реплики в промптах даны прямой речью с указанием, кто говорит;
  хором — только специально отмеченные фразы (финальные выкрики).
* **Надписи.** Футболка и табло сгенерированы **чистыми**, без кириллицы:
  «АЛЕКСАНДР №1», «С ДНЁМ РОЖДЕНИЯ», финальные титры и линия самолёта
  добавляются на монтаже. Модели надёжно портят кириллицу в кадре, а бриф это
  прямо допускает.
* **Финал.** Последняя сцена (`r3-10`, 5 с) — чистый отъезд камеры без речи,
  специально под финальные титры.

## После генерации

1. Проверить стыки: если на переходе между сценами заметен скачок, перегенерировать
   сцену — стартовый кадр берётся из соседней, поэтому пересобирать надо
   последующие (удалить их из манифеста).
2. Наложить титры: «СЛЕДУЮЩАЯ ВЫСОТА — ТВОЯ», «ЭКИПАЖ К ВЫЛЕТУ ГОТОВ», мелко
   «AI FAN VIDEO», надписи на футболке и табло.
3. Музыка поверх готового ролика:

   ```bash
   ffmpeg -i rolik-3.mp4 -i music.mp3 \
       -filter_complex "[1:a]volume=0.25[m];[0:a][m]amix=inputs=2:duration=first[a]" \
       -map 0:v -map "[a]" -c:v copy rolik-3-music.mp4
   ```

## Если что-то пошло не так

* **Речь обрывается на полуслове** — сцене мало секунд: поднять `duration` до 7–8
  или разбить сцену надвое.
* **Лица «плывут» между сценами** — усилить приметы в `preamble` (шрамы, повязка,
  цвет бутс) и перегенерировать сцену; сцепка по кадру держит внешность, но не идеально.
* **Нет звука** — проверить, что модель поддерживает `generate_audio`; скрипт
  предупредит о сценах без дорожки перед склейкой.
* **Латиница вместо русской речи** — добавить в промпт сцены «говорят по-русски»
  (в `preamble` это уже есть, но на отдельной сцене можно усилить).
