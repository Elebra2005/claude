# Бот «814 отправился — пора выходить»

Присылает в Telegram сообщение, когда автобус 814 уехал с конечной «6-я Радиальная».

## Как это работает

Раз в 30 секунд бот запрашивает у Яндекс.Карт прогноз прибытия 814 на
**первую остановку после конечной**. Пока автобус стоит на конечной,
прогноза нет или он большой. Когда автобус трогается, прогноз падает до
1–3 минут, и бот присылает уведомление. Следующее придёт, когда этот
автобус проедет остановку и к ней поедет следующий.

Уведомления приходят только в заданное окно (по умолчанию пн–пт 07:00–09:30 МСК).

## Настройка

1. **Токен.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. **ID остановки.** Откройте yandex.ru/maps и найдите 814. Нажмите на
   остановку, которая идёт **сразу после** «6-я Радиальная» в нужном
   направлении. В адресной строке будет `...masstransit[stopId]=stop__9643291...`.
   Нужна часть `stop__9643291`.
3. `cp .env.example .env` и заполните `TELEGRAM_BOT_TOKEN`, `STOP_ID`, `STOP_NAME`.
4. Запуск:
   ```bash
   docker compose up -d --build
   docker compose logs -f
   ```
   Без Docker: `pip install -r requirements.txt && python bot.py`.
5. Напишите боту `/start`. Потом укажите свой chat id из ответа в
   `ALLOWED_CHAT_IDS`, чтобы ботом не пользовались другие люди.

## Команды

- `/start` — подписаться
- `/status` — текущие прогнозы по остановке
- `/off`, `/on` — выключить и включить уведомления

## Параметры (.env)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `STOP_ID` | — | остановка, по прогнозу на которую определяется отправление |
| `DEPART_ETA_MIN` | `3` | прогноз не больше этого числа минут означает «уже едет». Лучше поставить чуть больше, чем время в пути от конечной до `STOP_ID` |
| `POLL_INTERVAL` | `30` | частота опроса, в секундах. Меньше 20 ставить не стоит, иначе Яндекс начнёт показывать капчу |
| `ACTIVE_DAYS` | `1-5` | дни недели (1=пн … 7=вс), например `1-5` или `1,3,5` |
| `ACTIVE_FROM` / `ACTIVE_TO` | `07:00` / `09:30` | окно уведомлений (МСК) |
| `ALLOWED_CHAT_IDS` | пусто | кому доступен бот, через запятую |

**Другой вариант.** Можно указать в `STOP_ID` **свою** остановку, а в
`DEPART_ETA_MIN` — время, за которое вы до неё доходите, плюс пару минут.
Тогда бот напишет в момент, когда пора выходить, чтобы успеть к автобусу.
Этот способ часто точнее: пробки учитываются автоматически.

## Ограничения

- Данные берутся из неофициального API Яндекс.Карт, которым пользуется сам сайт.
  Если Яндекс его поменяет, бот перестанет получать прогнозы. В этом случае
  `/status` покажет ошибку или «прогнозов нет».
- Если сервер находится не в России, Яндекс чаще показывает капчу. Об этом будет строка в логах.
- Проверка логики без сети: `python test_logic.py`.
