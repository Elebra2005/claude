# Бот «814 на остановке — пора выходить»

Присылает в Telegram сообщение, когда автобус 814 (в сторону «Платформа
Чертаново») подъезжает к остановке «Касимовская улица».

## Как это работает

Раз в 20 секунд бот запрашивает у Яндекс.Карт прогноз прибытия 814 на
остановку «Касимовская улица». Это тот же прогноз, что показан в блоке
«Прогноз прибытия» на Яндекс.Картах. Когда до автобуса остаётся не больше
минуты, бот присылает «🚌 814 на остановке «Касимовская улица» — пора
выходить!». Если автобус проскочил остановку между двумя опросами,
уведомление всё равно придёт. Повторов про тот же автобус не будет.

Уведомления приходят только в заданное окно (по умолчанию пн–пт 07:00–09:30 МСК).

## Настройка

1. **Токен.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. **ID остановки.** Откройте на yandex.ru/maps карточку остановки
   «Касимовская улица», где 814 идёт «до Платформа Чертаново». Скопируйте
   адрес страницы. В нём будет `masstransit[stopId]=stop__XXXXXXX`
   (или `%5BstopId%5D=stop__XXXXXXX`). Нужна часть `stop__XXXXXXX`.
3. `cp .env.example .env` и заполните `TELEGRAM_BOT_TOKEN` и `STOP_ID`.
4. Запуск:
   ```bash
   docker compose up -d --build
   docker compose logs -f
   ```
   Без Docker: `pip install -r requirements.txt && python bot.py`.
5. Напишите боту `/start`. Потом укажите свой chat id из ответа в
   `ALLOWED_CHAT_IDS`, чтобы ботом не пользовались другие люди.

## Команды

- `/start` — подписаться
- `/status` — текущие прогнозы по остановке
- `/off`, `/on` — выключить и включить уведомления

## Параметры (.env)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `STOP_ID` | — | остановка, к которой отслеживаем автобус |
| `STOP_NAME` | `Касимовская улица` | название для сообщений |
| `NOTIFY_ETA_MIN` | `1` | уведомлять, когда до автобуса осталось не больше N минут. Если хотите выходить заранее, поставьте время, за которое доходите до остановки |
| `POLL_INTERVAL` | `20` | частота опроса, в секундах. Меньше 20 ставить не стоит, иначе Яндекс начнёт показывать капчу |
| `ACTIVE_DAYS` | `1-5` | дни недели (1=пн … 7=вс), например `1-5` или `1,3,5` |
| `ACTIVE_FROM` / `ACTIVE_TO` | `07:00` / `09:30` | окно уведомлений (МСК) |
| `ALLOWED_CHAT_IDS` | пусто | кому доступен бот, через запятую |

## Ограничения

- Данные берутся из неофициального API Яндекс.Карт, которым пользуется сам сайт.
  Если Яндекс его поменяет, бот перестанет получать прогнозы. В этом случае
  `/status` покажет ошибку или «прогнозов нет».
- Если сервер находится не в России, Яндекс чаще показывает капчу. Об этом будет строка в логах.
- Проверка логики без сети: `python test_logic.py`.
