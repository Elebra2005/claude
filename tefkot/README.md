# ТЕФКОТ 770 — обвязка стального реактора 50 л

## Итоговые файлы

| Файл | Что это |
|---|---|
| `tefkot-770-reaktor-50l.html` | Проект: решения, масштаб ×3, узлы, материалы, уставки, спецификация, регламент |
| `tefkot-770-skhema.vsdx` | Технологическая схема (принципиальная), Visio, A3 |
| `chertezh/tefkot-770-sborka-A1.vsdx` | Монтажная схема установки в сборе, Visio, A1 |
| `chertezh/tefkot-770-montazhnye-chertezhi.vsdx` | Полный комплект 8 листов (сборка A1 + листы 2–8 A3), Visio |
| `chertezh/tefkot-770-montazhnye-chertezhi.pdf` | Тот же комплект в PDF для печати |
| `chertezh/list-N.svg`, `chertezh/skhema.svg` | Листы в SVG |
| `3d/tefkot-770-ustanovka.step` | 3D-модель установки в сборе (STEP), см. `3d/README.md` |
| `3d/viewer.html` + `.glb` | Просмотр 3D в браузере |
| `zamery-chek-list.html` | Чек-лист замеров на объекте |

Листы комплекта: 1 — установка в сборе; 2 — реактор R-1 и таблица штуцеров; 3 — E-1, подача MeSiCl₃ / PDMS-OH насосом P-3, узлы P2/P3/P4;
4 — гребёнка (шпунт, аварийный сброс, аргон, вакуум, атмосфера), коллектор сбросов; 5 — генератор G-1 и колонны осушки; 6 — аргон, вакуум, теплоноситель;
7 — выгрузка и фильтрация; 8 — ведомость кламповых соединений (70 шт.); 9 — условные обозначения.

Красным со знаком «?» — размеры и присоединения, которые нужно уточнить замером или у поставщика.

## Пересборка и проверка

```
cd tefkot
python3 tools/cherteg.py        # монтажные чертежи → chertezh/*.vsdx, *.svg
python3 tools/scheme_vsdx.py    # технологическая схема из HTML → tefkot-770-skhema.vsdx
python3 tools/check.py          # проверка чертежей
python3 tools/check_svg.py      # проверка технологической схемы
python3 tools/step_model.py     # 3D-модель → 3d/*.step, *.glb
```

Проверка ищет: краны, клапаны, клампы и переходы, не присоединённые к линии с обеих сторон; фланцевые клампы не на стыке;
висящие концы трубопроводов; наложения подписей друг на друга, на номера соединений, на символы арматуры, на линии и на окружности.
Итог по всем листам: 0 замечаний.
